# Ekansh & Neha · Wedding

A wedding invitation that behaves like an iPhone. Guests unlock the lock screen with a Ganesha blessing, then land on a home screen whose apps actually open: the invitation in Safari, the calendar, the venue in Maps, an illustrated album, a YouTube-style music app, a match card for the arranged marriage, a calculator and settings.

Everything is in English, built for a North Indian wedding on **Friday, 15 January 2027 at 5:00 PM** at **The Grandeur by Lavanya banquet, A-15, Mahatma Gandhi Rd, Block A, Wazirpur Industrial Area, Ashok Vihar, Delhi 110052**.

## What is inside

- **Lock screen** with a live clock in 12-hour format, the wedding date, a music card and swipe up or tap to open.
- **Ganesha unlock ceremony**: a frosted iOS-style card with the idol, "Shree Ganeshaya Namah", the couple's names and the ceremony, shown for about four seconds.
- **Home screen** with iOS widgets: calendar, venue map, an apps folder and a Safari invitation card.
- **Safari**: the full invitation page in the browser, with the evening's programme, venue, dress code and add-to-calendar.
- **Photos**: a masonry album of line-art plates — a garland exchange, a palanquin, a baraat horse, a mandap, diyas, peacocks — plus three short loops made by slowly pushing into those same plates. No photography at all, and no real couple photos.
- **YouTube**: a dark, native-feeling YouTube app with a player, progress, like and share, filter chips and a song list. All five songs play through the YouTube IFrame player.
- **Rishta**: an arranged-marriage match card with the couple, the details, a gunas/stat row and the evening's order.
- **Calendar, Notes, Messages, Calculator, Settings**: small iOS-style apps with invitation copy. Notes has the invite as a note; Messages has a short thread about the wedding.
- **One audio engine**: the lock-screen card and the YouTube app share a single YouTube player, so starting a song in one place always stops the other. There is no second audio element and no double music.

| Tere Sang Yaara | Rustom | Classic love |
| Raataan Lambiyan | Shershaah | Lyric upload, chosen because it embeds reliably |

YouTube blocks embedding for some label uploads (player error 150). If you swap a song and it does not play, open the video on YouTube, check that it is public or unlisted and that embedding is allowed, or pick an official lyric video. The player reports the failure on screen instead of failing silently.

## Run it locally

```bash
pnpm install
pnpm dev
```

Node 20 or newer is recommended. `pnpm build` type-checks and produces `dist/`.

## Customise

Almost all copy comes from two files:

- `src/invitation/data.ts`: names, date, time, venue, address, hosts, hashtag, the maps link and the playlist.
- `components/calendarData.ts`: the calendar widget and calendar app, derived from the same wedding data.

For the rest:

| What | Where |
| --- | --- |
| Page title, description, social preview | `index.html` |
| PWA name and colours | `public/site.webmanifest` |
| Album order and shape | `src/PhotosPage.tsx` |
| Album and wallpaper artwork | `scripts/prepare-assets.mjs` |
| Icons | `public/icons/`, generated by the same script |
| Copy inside apps | `src/InvitationPage.tsx`, `src/RishtaPage.tsx`, `src/NotesPage.tsx`, `src/MessagesPage.tsx`, `src/SettingsPage.tsx` |

### Replace the artwork

Every plate is built from a Pixabay illustration (free to use, no attribution
required, see `CREDITS.md`). The script downloads each source once into
`.tools/art` and lays it on cream or maroon paper with a gold frame, recolouring
line art to a single ink so the album stays consistent. To use your own, replace
the files in `public/photos/` and the wallpaper files, or edit the `ART` map and
`GALLERY` list in the script.

Regenerating the set:

```bash
pnpm assets
```

This needs `sharp` (already a dev dependency) and network access for the first
run. The three album loops need ffmpeg; point at a local binary with
`FFMPEG_PATH`, or install `ffmpeg-static` in `.tools` as this repo does.

### Uploaded media

Settings → Invitation Media lets you preview photos and videos from your own device. Uploads are stored in the browser only (IndexedDB) and are perfect for a quick preview. To show them to every guest, copy them into `public/` and redeploy.

## Deploy to Vercel (free Hobby tier)

This is a static Vite site, so it fits the free non-commercial Hobby plan with no server or database.

1. Push this repository to GitHub (already done if you are reading it there).
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel detects Vite. Keep the defaults: install `pnpm install`, build `pnpm build`, output `dist`.
4. Deploy. Every later push to `main` redeploys automatically.

`vercel.json` already sets long-lived caching for the generated assets and photos. No environment variables are needed.

## Notes

- The YouTube player is the only network dependency at runtime. If it is blocked, the music card shows a short error and the rest of the invitation still works.
- The invitation is a single page. No router, no backend, no analytics.
- The site is meant to be shared as a link. Add it to a home screen on iOS for the full-screen experience.
